3D deposit models

One model per project, built from every NI 43-101 technical report and drill-result release we hold for it — collars and intercepts in 3D on real terrain, drill intervals coloured by grade, an inverse-distance block model on the report's own block size, and contained metal checked against the published resource.

Grades are inverse-distance estimates for visualisation, not a mineral resource estimate. Every model page lists the exact reports and releases it was built from — verify figures against those filings before relying on them.
